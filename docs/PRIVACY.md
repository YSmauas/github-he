# פרטיות

## מה הסקריפט עושה ברשת
- **ברירת מחדל:** בדיקת עדכון מילון כל כמה שעות מ-`raw.githubusercontent.com` (עם גיבוי ב-`cdn.jsdelivr.net`). הבקשה היא GET בלבד ואינה שולחת שום מידע עליכם. אפשר לכבות בתפריט.
- **רק כשאתם לוחצים "שליחה":** יצירת Issue במאגר הזה דרך האתר github.com (אותו origin, ה-session שלכם, בלי טוקן).
- אין אנליטיקה, אין טלמטריה ואין שרת צד שלישי.

## מה נשמר מקומית (באחסון של Tampermonkey)
- **הגדרות:** מופעל/כבוי, כיווניות, עדכון אוטומטי.
- **מטמון מילון** שהתקבל מהמאגר.
- **מילון אישי** (אם ייבאתם).
- **איסוף** (רק כשהוא מופעל): לכל מחרוזת — הטקסט האנגלי, כמה פעמים נראתה, תבניות עמוד (למשל `/:owner/:repo/issues/:n`, לא כתובות אמיתיות), גיבוב של שם ה-owner (לא השם עצמו), ותגית+מחלקה של האלמנט.

## מה האיסוף לא אוסף
- מחרוזות מתוך דפי **repository פרטי**.
- תוכן משתמשים: README, הערות, כותרות issue, קוד, הודעות commit, שמות משתמש/repo/branch (מזוהים לפי סלקטורים ולפי צורת הטקסט).
- כתובות, אימיילים, hash של commit, תאריכים מוחלטים, טקסט בעברית.
- מחרוזות ארוכות מ-120 תווים.
- מחרוזות שנראו פחות מ-3 פעמים או בפחות מ-2 סוגי עמודים.

> אין הגנה מושלמת: האתר משתנה, ויתכן שטקסט אישי יעבור את הסינון. לכן **תמיד** מוצגת לכם הרשימה המלאה לפני שליחה, ואפשר לבטל כל פריט.

## מה נשלח ב"שליחה למפתח"
Issue **ציבורי** במאגר הזה, תחת חשבון GitHub שלכם. הוא כולל:
- גרסת הסקריפט וגרסת המילון;
- לכל מחרוזת שאישרתם: הטקסט האנגלי, `kind`, מספר הופעות, תבניות עמוד, הקשר (`TAG.class`).

הוא **לא** כולל: כתובות אמיתיות, שמות repositories, או תוכן מהדפים שלכם.

## מחיקה
- תפריט ← "מחיקת מחרוזות שנאספו".
- Issue שנשלח: אפשר לסגור או למחוק (לפנות למתחזק).
- מחיקת כל נתוני הסקריפט: הסרת הסקריפט מ-Tampermonkey.
